## Phase Goal

**As a** developer, **I want to** see live data in/out for chunk through align — raw model text, empty-parse callouts and format flags included — **so that** I can follow what each stage of one `lx.extract()` call received and produced, without needing a warm model yet.

This plan: the parse stage — raw text + format flags in, ungrounded snapshots out, and a callout that tells the truth about an empty parse.

## Acceptance Criteria

- [ ] `[parse]` prints raw model text, format/fence/wrapper flags, and parsed snapshots from one offline extract (STG-03, STG-09)
- [ ] Empty parse is called out in words next to the raw text; valid empty list gets a different, accurate sentence (STG-09)

## Planner assumptions (specless edges — review)

- **A3 truthful callout chosen:** an empty result is diagnosed by re-running the original `resolve` with `suppress_parse_errors=False` (pure, no model call). Error → `empty_parse_message` + error text; no error → `empty_list_message`. Reversible: dropping the re-run reverts to always printing `empty_parse_message`.
- **Diagnosis lives in the wrapper, wording in the printer:** the record stores `parse_error: str | None`; the printer picks the config sentence. Keeps records primitive and messages in config.
- **`empty_list_message` wording (proposed):** "Model returned a valid empty extraction list; nothing was omitted." — reviewer may reword in config without code change.
