## Phase Goal

**As a** developer, **I want to** know the live run made exactly one `lx.extract()` and exactly one `gemma3:4b` inference, **so that** the printed walkthrough is the story of that one local call and nothing else.

## Acceptance Criteria

- [ ] Run ends with an explicit single-call line; 0/2 infers or a multi-prompt batch fail with exit 1 (RUN-03)
- [ ] Over-long sample is refused before any network call (RUN-03, one chunk)
- [ ] Real `gemma3:4b` run passes end-to-end on this machine (RUN-01 success criterion 1)
- [ ] COVERAGE.md written

## Planner assumptions (specless edges — review)

- **"One infer" = one `OllamaLanguageModel.infer` call carrying one prompt.** With one chunk and default `batch_length=10`, `extract` makes one infer call; the prompt-count check catches multi-chunk drift that would otherwise be one call with several prompts (several `/api/generate` requests).
- **Infer count source:** the Phase 4 model-stage records (one per infer call). If Phase 4 records are per-yield rather than per-call, the executor counts calls via the record field Phase 4 documents in its SUMMARY — do not add a second wrap on `infer`.
- **Live test gating:** `TRACE_LIVE_OLLAMA=1` env var (absltest skipUnless), mirroring the Makefile's exclusion of live tests from default runs.
