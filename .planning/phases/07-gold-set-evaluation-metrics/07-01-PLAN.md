## Phase Goal

**As a** library user, **I want to** `evaluate(predicted, gold)` that scores extractions against a labeled gold set and returns per-class and micro precision/recall/F1, **so that** I can run a CI regression check without a custom eval harness.

## Acceptance Criteria (this plan)

- [ ] `prf_from_counts` and `EvaluationReport` exist with frozen hand-worked metric values (EVAL-01 foundation, EVAL-04 metric formulas)
- [ ] Empty counts yield 0.0 for P, R, and F1 (resolved empty probe)
- [ ] Package registered in `pyproject.toml` (D-01)

## Planner assumptions (specless edges + RESEARCH discretion)

- **Empty → 0.0 (A1):** when TP=FP=FN=0, precision/recall/f1 are all 0.0 (not NaN / not raise).
- **Micro definition:** global TP/FP/FN then one `prf_from_counts` — never average of per-class F1.
- **Field names (discretion):** `ClassScore(precision, recall, f1, tp, fp, fn)` frozen; `EvaluationReport(per_class, micro)`.
- **per_class key order:** keys sorted alphabetically in `report_from_counts` for stable reports (EVAL-01 ordering probe).
- **Tracer foundation:** this plan freezes the metrics layer that later plans wire into `evaluate` (D-06); no end-to-end evaluate yet.
