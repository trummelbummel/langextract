## Planner assumptions (specless edges)

- **Threshold contract:** match when IoU ≥ threshold (not strict &gt;). Default threshold 0.5 on SpanIoU.__init__.
- **Touching spans:** half-open [0,5) and [5,10) → inter=0 → IoU 0.0 (adjacency separate, not merge).
- **Partial CharInterval:** missing start or end → 0.0 (same as None interval).
- **AttributesEqual (A5):** Python `==` on attributes (None == None is True; list order in values matters).
