## Phase Goal

**As a** library user, **I want to** `evaluate(predicted, gold)` that scores extractions against a labeled gold set and returns per-class and micro precision/recall/F1, **so that** I can run a CI regression check without a custom eval harness.

## Acceptance Criteria (this plan)

- [ ] Greedy 1:1 matching with deterministic IoU-desc tie-break (EVAL-03)
- [ ] Duplicate preds leave unmatched FP candidates for evaluate (EVAL-04)
- [ ] Empty inputs yield no matches (empty probe)

## Planner assumptions (specless edges)

- **Sort key:** `(-iou, pred_index, gold_index)` — lower indices win ties (RESEARCH Pitfall 4).
- **Return type:** `list[tuple[int, int]]` of matched (pred_idx, gold_idx) in greedy assignment order (walk order after sort).
- **Score function:** default `score_fn=span_iou` from criteria; injectable for tests but evaluate will pass span_iou.
- **Criteria failure:** pair omitted from candidates even if IoU is high (class mismatch).
