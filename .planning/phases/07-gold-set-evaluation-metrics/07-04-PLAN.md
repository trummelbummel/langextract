## Phase Goal

**As a** library user, **I want to** `evaluate(predicted, gold)` that scores extractions against a labeled gold set and returns per-class and micro precision/recall/F1, **so that** I can run a CI regression check without a custom eval harness.

## Acceptance Criteria (this plan)

- [ ] End-to-end `evaluate` returns EvaluationReport for RESEARCH hand-worked cases (EVAL-01..04)
- [ ] Convenience flags XOR `criteria=` (D-04)
- [ ] document_id set mismatch raises ValueError (A2)
- [ ] Lazy `lx.evaluation` export registered (A4)

## Planner assumptions (specless edges)

- **Pairing (A2):** require identical `document_id` sets; raise `ValueError` listing IDs only in predicted or only in gold. Duplicate IDs within a side raise `ValueError` (no first-wins fallback).
- **Counters:** TP/FP use predicted.extraction_class; FN use gold.extraction_class (RESEARCH Pitfall 8).
- **Default kwargs:** `iou_threshold=0.5`, `match_attributes=False`, `text_eval_func=None`, `criteria=None`.
- **XOR:** if `criteria is not None`, then `iou_threshold` must be 0.5, `match_attributes` False, and `text_eval_func` None — else ValueError.
- **Explicit document_id in all fixtures** (Pitfall 1).
