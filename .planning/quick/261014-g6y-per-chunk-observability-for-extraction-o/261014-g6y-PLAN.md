`on_event` callable receives frozen event dataclasses for chunk start/finish and

the Ollama provider fills. Implements spec slices 1 → 3 → 5 of
`chunk-observability-spec.md` (the locked design; treated as CONTEXT).

of a single debug total and silent `[]` on parse failure.

`extraction.py`, `TokenUsage` + `ScoredOutput.usage`, Ollama usage mapping,
`tests/chunk_events_test.py`.

Locked decisions (spec "Decisions" + "Rules"; referenced below as D-01..D-07):
- D-01: `on_event` is a plain `Callable[[ExtractionEvent], None]`, not a Protocol.
- D-02: `chunk_index` is per document, paired with `document_id`.
- D-03: `parse_failed` fires even when parse errors are suppressed.
- D-04: `on_event` is accepted by `extract()` and by `Annotator.annotate_text` / `annotate_documents`.
- D-05: Events are emitted only from the calling thread; observer exceptions are caught and logged once per run.
- D-06: Durations use `time.perf_counter()`; `duration_s` is measured in the annotator and includes the wait for the whole batch.
- D-07: `ScoredOutput.usage` is optional and added as the last field so existing providers keep working.
- Event names are stable: fields are only ever added, never renamed.

Codebase facts the executor needs (verified):
- `Annotator._annotate_documents_single_pass` (annotation.py ~285-447) is the only
  place chunks are inferred: it iterates `batch_iter` (progress-bar wrapper over
  `chunking.make_batches_of_textchunk`), calls `self._language_model.infer(...)`
  at ~392, then per chunk `resolver.resolve(scored_outputs[0].output, debug=..., suppress_parse_errors=..., **kwargs)` at ~406 and `resolver.align(...)` at ~424.
- `suppress_parse_errors` reaches `_annotate_documents_single_pass` through
  `**kwargs` from `extract()` (`alignment_kwargs.setdefault("suppress_parse_errors", True)`, extraction.py:398). `_annotate_documents_sequential_passes` (~449) calls single-pass once per `pass_num`.

- `TextChunk` exposes `document_id`, `char_interval.start_pos/end_pos` (may be None -> treat as None in the event).
- `Resolver.resolve` raises `ResolverParsingError` (from `FormatError` or `ValueError`) when `suppress_parse_errors=False`; when True it logs "Chunk omitted from results (parse error|schema error)" and returns `[]` (resolver.py:321-351).
